# IoT Intrusion Detection System using Machine Learning

## 📌 Project Overview
This project is an IoT-based Intrusion Detection System (IDS) developed using Machine Learning techniques to detect malicious network activities and cyber attacks in IoT environments.

The system collects network traffic data, analyzes suspicious behavior, and classifies attacks using trained ML models. The project also integrates MQTT communication and a web dashboard for monitoring.

---

## 🚀 Features
- Real-time intrusion detection
- Machine Learning based attack classification
- MQTT communication support
- Flask-based web application
- Attack simulation support
- Network traffic monitoring
- IoT device integration
- Dashboard visualization

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/edj-abilash/Project.git
```

### 2. Open Project Folder

```bash
cd Project
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Environment

#### Windows
```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Application

```bash
python app.py
```
